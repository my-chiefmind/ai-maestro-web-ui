# Requirements

- Node.js 20.19.x, or Node.js 22.12 or newer
- `@mychiefmind/ai-maestro` `>=0.6.7 <0.7` (a peer dependency). A new cockpit folder lists it in
  its `package.json`; inside a project, the project installs it.

A project on an older kit is refused with one line that says how to update it.
